# 🎤 OpenKTV Rust — 全新重製版

OpenKTV 是一套免費開源的 AI 卡拉 OK 系統，讓使用者能夠透過 YouTube 影片，自動製作伴唱歌曲，並在電腦或電視上享受 KTV 體驗。

本專案是原本 [OpenKTV-AI（Python 版本）](https://github.com/ddmmbb-2/OpenKTV-AI/) 的全新重製版。

這次不再使用 Python + Flask 作為主要操作介面，而是改用 **Rust 開發 Windows 原生桌面程式**，重新設計整體架構、播放流程與使用介面，並增加更多 KTV 實用功能。

## ✨ 主要功能

- 🎬 **YouTube 影音下載**：輸入 YouTube 網址，自動下載影片與音訊。
- 🤖 **AI 人聲分離**：使用 Demucs AI 模型，自動將歌曲分離為人聲與伴奏。
- 🎵 **自動合成伴唱影片**：完成音軌處理與封裝，建立可直接播放的 KTV 歌曲。
- 🎤 **原唱／伴奏切換**：播放過程中自由切換。
- 🎹 **升降 KEY**：支援即時升降音調，不必重新處理歌曲。
- 📺 **原生桌面播放器**：整合 mpv 影片播放核心。
- 📱 **手機無線麥克風**：手機連接同一區域網路後，可透過瀏覽器作為無線 MIC。
- 🎶 **手機點歌與遙控**：支援搜尋、點歌、切歌、升降 KEY 及待播清單。
- 💻 **Windows EXE 執行**：提供編譯好的程式，不需要另外安裝 Rust 開發環境。

## 🔄 與舊版 Python 的差異

| 項目 | 舊版 OpenKTV-AI | 新版 OpenKTV Rust |
|---|---|---|
| 主要程式 | Python | Rust |
| 操作介面 | Web / Flask | Rust 原生 GUI |
| AI 人聲分離 | Spleeter | Demucs |
| 播放核心 | 網頁播放器 | mpv |
| 即時升降 KEY | — | ✅ |
| 手機無線 MIC | — | ✅ |
| 手機遙控點歌 | ✅ | ✅ |
| Windows EXE | ✅ | ✅ |

**這不是舊版的直接移植，而是一次重新開發。** 目標是讓 KTV 系統更容易操作、維護與持續擴充。

## 📦 下載與安裝

本次 Release 已提供 Windows 打包 ZIP，內含：

- `openktv-rust.exe`：KTV 主程式
- `tools/`：程式所需的外部工具及相關環境

### 使用方法

1. 下載 Release 中的 ZIP 壓縮檔。
2. 解壓縮至電腦上的資料夾。
3. 保持 EXE 與 `tools` 資料夾的相對位置。
4. 執行 `openktv-rust.exe`。
5. 透過程式介面下載歌曲、製作伴唱並開始點歌。

使用 YouTube 下載與部分 AI 處理功能時，可能需要網路連線；手機功能則需要電腦與手機處於可以互相連線的區域網路環境。

## 🛠️ 開發技術

- **Rust**：桌面應用程式與主要控制邏輯
- **mpv**：影音播放與音調調整
- **Demucs**：AI 人聲與伴奏分離
- **yt-dlp**：YouTube 影音下載
- **FFmpeg**：影音音軌處理及合成
- **WebSocket / HTTPS**：手機與電腦之間的連線與操作

其中 AI 處理仍使用外部模型與相關執行環境，並非全部功能都以純 Rust 實作。
